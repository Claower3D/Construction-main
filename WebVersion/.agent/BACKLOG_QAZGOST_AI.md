## 📚 Условные обозначения

### Приоритеты

| Приоритет | Описание |
|-----------|----------|
| **P0** | Критично для MVP/запуска продаж |
| **P1** | Важно для полноценного продукта |
| **P2** | Улучшения и оптимизации |
| **P3** | Будущие фичи |

### Статусы

| Статус | Описание |
|--------|----------|
| ✅ Done | Реализовано |
| 🔄 In Progress | В работе |
| 📋 To Do | Запланировано |
| ⏸️ On Hold | Отложено |

### Оценка (Story Points)

- **1-2 SP**: Маленькая задача (до 4 часов)
- **3-5 SP**: Средняя задача (1-2 дня)
- **8-13 SP**: Большая задача (3-5 дней)
- **21+ SP**: Эпик, требует декомпозиции
