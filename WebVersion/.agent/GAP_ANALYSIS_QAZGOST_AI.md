## B2. Бизнес-правила — Анализ

| № | Правило | Статус | Реализация |
|---|---------|--------|------------|
| 1 | Менее 2 фото → уведомление | ⚠️ Частично | `estimateService.js` CONFIG.MIN_PHOTOS_REQUIRED. Уведомление базовое. |
| 2 | Confidence < 0.6 → инженерная проверка | ⚠️ Частично | Есть поле confidence. Автоматическая маркировка ❌НЕТ. |
| 3 | Расхождение >10% → флаг инженеру | ❌ Не реализовано | — |
| 4 | Исполнитель не ответил 24ч → предложить другим | ❌ Не реализовано | Нет таймеров/cron. |
| 5 | Клиент изменил параметры → v+1 | ✅ Реализовано | `estimateService.js` создаёт новую версию. |
| 6 | AI обнаружил глубину < нормы → доработка | ❌ Не реализовано | AI-анализ фото заглушка. |
| 7 | Подрядчик не меняет статус N часов → напоминание | ❌ Не реализовано | Нет таймеров. |
| 8 | Клиент не подтверждает 72ч → авто-принятие | ❌ Не реализовано | Нет таймеров. |
| 9 | Отсутствие данных → ошибка с обязательными полями | ✅ Реализовано | validate() в моделях. |
| 10 | AI-модуль обновлён → версия модели сохраняется | ⚠️ Частично | model_version в EstimateVersion. Уведомление ❌НЕТ. |

## 🔴 Критические пробелы (требуют приоритетной разработки)

### P0 — Критично для MVP

1. **Чат и уведомления** — отсутствует полностью
2. **Таймеры/напоминания** — нет cron/scheduler для бизнес-правил
3. **AI-анализ фото** — заглушки, реальный анализ не реализован
4. **Diff-просмотр версий** — спецификация требует, UI отсутствует

### P1 — Важно для полноценного запуска

1. **Календарь работ** для исполнителей
2. **Админ-панель** — управление прайсами, модерация, споры
3. **Escrow-схема** платежей
4. **Акты выполненных работ** — полноценные PDF

### P2 — Улучшения

1. **KPI-дашборды** и аналитика
2. **Авто-подбор подрядчиков** по региону/рейтингу
3. **AI-chat** для типовых вопросов
