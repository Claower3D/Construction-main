# Планирование спринта

## Входные параметры

- **SPRINT_NUMBER**: Номер спринта (1, 2, 3...)
- **SPRINT_GOAL**: Цель спринта
- **DURATION**: Длительность (обычно 2 недели)

## Шаги

### 1. Подготовка спринта

Открыть файл `.agent/BACKLOG_QAZGOST_AI.md` и:

1. Выбрать User Stories для спринта (обычно 20-30 SP):
   - Приоритет P0 в первую очередь
   - Учитывать зависимости
   - Учитывать velocity команды

2. Создать файл спринта:

```markdown
# Sprint {N}: {SPRINT_GOAL}

## Период: {START_DATE} — {END_DATE}

## Цель спринта
{Описание цели}

## User Stories

| US | Название | SP | Статус |
|----|----------|-----|--------|
| US-X.Y | Название | N | 📋 |
| ... | ... | ... | ... |

**Итого**: XX SP

## Daily Log

### День 1 ({DATE})
- [ ] Task 1
- [ ] Task 2

### День 2 ({DATE})
...

## Blockers
- (пусто)

## Ретроспектива
- Что получилось:
- Что улучшить:
- Скорость (velocity):
```

### 2. Начало спринта

Для каждой US в спринте:

1. Создать план реализации (см. `/implement-user-story`)
2. Разбить на дневные задачи
3. Оценить риски и зависимости

### 3. Ежедневный процесс

**Утро:**

- [ ] Проверить статус задач
- [ ] Обновить прогресс в sprint файле
- [ ] Определить задачи на сегодня

**В течение дня:**

- Выполнять задачи по плану
- Фиксировать blockers
- Обновлять статусы

**Вечер:**

- [ ] Отметить выполненное
- [ ] Обновить Daily Log

### 4. Завершение User Story

Когда US выполнена:

1. Проверить все критерии приёмки
2. Обновить статус в sprint файле: `📋` → `✅`
3. Обновить статус в `BACKLOG_QAZGOST_AI.md`

### 5. Завершение спринта

**Подсчёт velocity:**

```
Velocity = Сумма SP завершённых US
```

**Ретроспектива:**

- Что получилось хорошо?
- Что можно улучшить?
- Какие blockers были?

**Обновление документации:**

- [ ] Все US в бэклоге обновлены
- [ ] Sprint файл завершён
- [ ] Velocity записана для планирования

### 6. Планирование следующего спринта

На основе:

- Velocity текущего спринта
- Оставшихся P0 задач
- Новых требований

## Шаблон Sprint файла

Создать: `.agent/SPRINT_{N}.md`

```markdown
# Sprint {N}: {GOAL}

## Информация
- **Период**: DD.MM — DD.MM
- **Velocity план**: XX SP
- **Velocity факт**: — (заполнить в конце)

## User Stories

### ✅ Завершённые
| US | Название | SP |
|----|----------|-----|

### 🔄 В работе
| US | Название | SP | Прогресс |
|----|----------|-----|----------|

### 📋 Запланированные
| US | Название | SP |
|----|----------|-----|

## Daily Standup Log

### {DATE}
**Сделано:** ...
**Планируется:** ...
**Blockers:** ...

## Blockers & Risks

| Blocker | Влияние | Решение |
|---------|---------|---------|

## Ретроспектива

### Что получилось ✅
- 

### Что улучшить ⚠️
- 

### Идеи 💡
- 

## Метрики
- Velocity: X SP
- Количество US: X
- Blockers: X
```

## Чек-лист спринта

### Начало

- [ ] Sprint файл создан

- [ ] Зависимости определены
- [ ] Цель спринта ясна

### В процессе

- [ ] Daily log обновляется
- [ ] Blockers фиксируются
- [ ] Статусы актуальны

### Завершение

- [ ] Все US проверены
- [ ] Velocity подсчитана
- [ ] Ретроспектива проведена
- [ ] Бэклог обновлён
