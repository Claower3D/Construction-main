# Запуск веб-версии

## Шаги

// turbo-all

1. Перейти в директорию WebVersion:

```bash
cd "c:\Users\User\Desktop\Моя программа\новая прога от гугла\WebVersion"
```

1. Запустить локальный сервер:

```bash
npx -y http-server . -p 8080 -o
```

## Результат

- Браузер откроется на <http://localhost:8080>
- Приложение готово к тестированию

## Остановка

- Нажать Ctrl+C в терминале для остановки сервера
