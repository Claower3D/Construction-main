# Реализация User Story

## Входные параметры

- **US_ID**: Идентификатор User Story (например: US-1.1)
- **US_TITLE**: Название User Story

## Шаги

### 1. Найти User Story в бэклоге

Открыть файл `.agent/BACKLOG_QAZGOST_AI.md` и найти US по ID.

Скопировать:

- Описание (Как... Я хочу... Чтобы...)
- Критерии приёмки
- Технические задачи (если есть)

### 2. Анализ зависимостей

Проверить:

- [ ] Какие модели нужны? (существуют или создать)
- [ ] Какие сервисы нужны? (существуют или создать)
- [ ] Какой UI нужен? (новая страница или компонент)
- [ ] Есть ли зависимости от других US?

### 3. Создать план реализации

Файл: `.agent/{US_ID}_PLAN.md`

```markdown
# План реализации {US_ID}: {US_TITLE}

## Описание
{копия из бэклога}

## Технические задачи

### Модели
- [ ] Создать/обновить модель X в {file}.js

### Сервисы  
- [ ] Создать/обновить метод Y в {service}.js

### UI
- [ ] Добавить компонент Z в {ui}.js
- [ ] Добавить стили в {css}.css

### Интеграция
- [ ] Подключить в index.html
- [ ] Добавить в навигацию
- [ ] Обновить связанные компоненты

## Порядок реализации
1. Модели
2. Сервисы
3. UI
4. Интеграция
5. Тестирование

## Критерии готовности
{копия критериев приёмки}
```

### 4. Реализация по плану

Выполнять задачи по порядку:

1. **Модели** → Создать/обновить, проверить что экспортируются
2. **Сервисы** → Создать API, проверить в консоли
3. **UI** → Создать компоненты, подключить стили
4. **Интеграция** → Связать всё вместе
5. **Тестирование** → Проверить все критерии приёмки

### 5. Тестирование

// turbo

```bash
npx -y http-server "c:\Users\User\Desktop\Моя программа\новая прога от гугла\WebVersion" -p 8080 -o
```

Проверить:

- [ ] Все критерии приёмки выполнены
- [ ] Нет ошибок в консоли браузера
- [ ] UI работает корректно
- [ ] Данные сохраняются в localStorage

### 6. Обновить статус в бэклоге

В файле `.agent/BACKLOG_QAZGOST_AI.md`:

- Изменить статус с `📋 To Do` на `✅ Done`
- Добавить дату завершения

### 7. Коммит (если используется git)

```bash
git add .
git commit -m "feat({US_ID}): {краткое описание}"
```

## Чек-лист завершения

- [ ] Все технические задачи выполнены
- [ ] Все критерии приёмки проверены
- [ ] Нет ошибок в консоли
- [ ] Статус в бэклоге обновлён
- [ ] План удалён или перемещён в архив
