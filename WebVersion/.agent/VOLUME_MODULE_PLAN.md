## 2. Модели данных (volumeModels.js)

### VolumeCalculation

```javascript
{
  id: string,                    // Уникальный ID
  userId: string,                // ID заказчика
  title: string,                 // Название объекта/работы
  type: 'pile' | 'pit' | 'quarry', // Куча / Котлован / Карьер
  address: string,               // Адрес/гео (опционально)
  createdAt: Date,
  status: 'draft' | 'processing' | 'ready' | 'archived',
  
  // Фото (хранятся до генерации PDF)
  photosBefore: [{ src: string, quality: string }],
  photosAfter: [{ src: string, quality: string }],
  confidenceLevel: 'low' | 'medium' | 'high',
  
  // Комментарий и парсинг
  comment: string,               // Исходный комментарий
  parsedData: {
    material: { name, density, state },
    equipment: [{ type, model, capacity, count }],
    conditions: { distance_km, shifts, hours }
  },
  
  // Результаты расчёта
  results: {
    volumeBefore: number,        // м³ до
    volumeAfter: number,         // м³ после
    deltaVolume: number,         // ΔV м³
    mass: number,                // тонны
    buckets: number,             // ковши
    trips: number,               // рейсы
    hours: number,               // часы
    shifts: number,              // смены
    equipmentUsed: [],
    confidence: number           // 0-100%
  },
  
  // PDF
  pdfUrl: string,                // Ссылка на PDF акт
  pdfGeneratedAt: Date
}
```

## 4. Расчётный движок

### Формулы

```
Масса (т) = Объём (м³) × Плотность (т/м³) × Коэфф.разрыхления

Ковши = Объём (м³) / (Ёмкость ковша × fillFactor)

Рейсы = Масса (т) / (Грузоподъёмность × loadFactor)
   или = Объём (м³) / (Объём кузова × loadFactor)

Часы = (Рейсы × Цикл рейса в мин) / 60

Смены = Часы / 8 (или 12 для вахты)
```

## 5. NLP Парсер комментариев

### Распознаваемые сущности

- **Материал**: песок, глина, щебень, грунт, скала...
- **Состояние**: влажный, сухой, мокрый, плотный...
- **Техника**: экскаватор, самосвал, погрузчик + модель/ковш
- **Количество**: "2 экскаватора", "3 камаза"
- **Расстояние**: "5 км", "до 10 километров"
- **Время**: "8 часов", "2 смены", "дневная смена"

### Примеры комментариев

1. "Вывоз влажного песка экскаватором CAT 320 и 3 камазами на 5 км"
2. "Копка котлована, глина плотная. Работа в 2 смены"
3. "Щебень фракция 20-40, погрузка погрузчиком, 10 рейсов камаз"

## 6. UI Экраны

### 6.1 Список расчётов (История)

- Таблица/карточки: дата, объект, тип, объём, статус
- Фильтры: по дате, типу, статусу
- Кнопки: Скачать PDF, Удалить

### 6.2 Создание расчёта

- Форма: название, тип (куча/котлован/карьер), адрес
- Загрузка фото ДО/ПОСЛЕ
- Индикатор качества/уверенности
- Комментарий (обязательный)
- Кнопка "Анализировать"

### 6.3 ИИ распознал (подтверждение)

- Распознанный материал + выбор из справочника
- Распознанная техника + редактирование
- Условия (км, смены, часы)
- Предупреждения если данных мало
- Кнопки: "Пересчитать", "Подтвердить"

### 6.4 Результаты

- Карточки: объём ДО/ПОСЛЕ/ΔV
- Масса в тоннах
- Ковши, рейсы, часы, смены
- Индикатор уверенности
- Кнопка "Сформировать PDF акт"

## 7. PDF Акт

### Структура документа

1. **Шапка**: логотип, название, дата, ID
2. **Информация об объекте**: название, тип, адрес
3. **Таблица параметров**: материал, плотность, техника, условия
4. **Таблица результатов**: объёмы, масса, рейсы, ковши, часы
5. **Приложение**: фото ДО и ПОСЛЕ (миниатюры)
6. **Примечание**: "Расчёт выполнен оценочным методом. Точность: X%"
7. **Подвал**: контакты, дата генерации
