## 🏗️ Бизнес-модели

### B2C (Частные клиенты)

- Быстрый расчёт по фото
- Фиксированные пакеты услуг
- Онлайн-оплата картой
- Чат-бот консультант

### B2B (Корпоративные клиенты)

- Мультипроектный режим
- Персональные скидки
- Интеграция с 1С/ERP
- Многопользовательский доступ

### B2B2C (Партнёрская сеть)

- White-label решение
- API/SDK интеграция
- Revenue sharing

## 📞 Запуск проекта

```bash
# Веб-версия
cd WebVersion
npx serve -l 3000

# Backend (планируется)
cd backend
uvicorn app.main:app --reload

# AI Service (планируется)
cd ai-service
uvicorn app.main:app --port 8001
```
