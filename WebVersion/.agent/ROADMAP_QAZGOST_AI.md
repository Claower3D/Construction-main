## 🛠️ Технический стек

### Frontend

- **SPA:** Vanilla JS → Vue.js/React (v2.0)
- **UI:** Custom CSS + animations
- **State:** localStorage → Vuex/Redux
- **3D:** Three.js

### Backend

- **API Gateway:** FastAPI (Python)
- **AI Service:** FastAPI + PyTorch
- **Auth:** JWT + OAuth2
- **Queue:** Redis + Celery/Bull

### AI/ML

- **Object Detection:** YOLOv8
- **Depth Estimation:** MiDaS / ZoeDepth
- **LLM:** GPT-4 / Claude API
- **OCR:** Tesseract / EasyOCR

### Database

- **Primary:** PostgreSQL 15
- **TimeSeries:** TimescaleDB
- **Cache:** Redis
- **Search:** Elasticsearch

### Infrastructure

- **Cloud:** AWS / Yandex Cloud
- **Container:** Docker + Kubernetes
- **CI/CD:** GitHub Actions
- **Monitoring:** Grafana + Prometheus
