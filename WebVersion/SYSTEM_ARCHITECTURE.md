## 2.1 auth-engine.js

### Логика входа

```
1. Пользователь вводит email/телефон + пароль
2. AuthEngine.login(credentials)
3. Проверка в localStorage (демо) или API (прод)
4. Создание сессии
5. Сохранение токена
6. Редирект по роли
```

| Роль | Главная страница | Доступ |

| `customer` | Мои заказы | Создание заказов, просмотр смет |
| `executor` | Доступные заказы | Поиск работы, отклики |
| `admin` | Админ-панель | Полный доступ |

## 3.2 financeService.js — API финансов

### Основные операции

| Метод | Описание |
|-------|----------|
| `FinanceService.Wallet.getBalance(userId)` | Получить баланс |
| `FinanceService.Wallet.deposit(userId, amount)` | Пополнить |
| `FinanceService.Wallet.withdraw(userId, amount)` | Вывести |
| `FinanceService.Wallet.freeze(userId, amount, orderId)` | Заморозить для сделки |
| `FinanceService.Wallet.release(userId, amount, orderId)` | Разморозить |
| `FinanceService.Payment.pay(fromId, toId, amount)` | Перевод |

### Логика оплаты заказа

```
1. Заказчик подтверждает заказ
2. Система замораживает сумму на балансе
3. Исполнитель выполняет работу
4. Заказчик принимает работу
5. Система переводит деньги исполнителю (минус комиссия 3%)
6. Комиссия зачисляется на счёт платформы
```

### Диаграмма

```
┌─────────────┐     freeze      ┌─────────────┐
│  Заказчик   │────────────────▶│  Frozen     │
│  Balance    │                 │  Amount     │
└─────────────┘                 └──────┬──────┘
                                       │ complete
                                       ▼
┌─────────────┐     97%         ┌─────────────┐
│ Исполнитель │◀────────────────│  Release    │
│  Balance    │                 └──────┬──────┘
└─────────────┘                        │ 3%
                                       ▼
                                ┌─────────────┐
                                │  Platform   │
                                │  Revenue    │
                                └─────────────┘
```

## 5.1 aiEngineerValidator.js — Валидатор

### Правила валидации

| Правило | Проверка | Ошибка |
|---------|----------|--------|
| `MIN_AREA` | area >= 1 м² | Слишком маленькая площадь |
| `MAX_AREA` | area <= 10000 м² | Слишком большая площадь |
| `MIN_PRICE` | price >= 10000 ₸ | Цена ниже порога |
| `MAX_PRICE` | price <= 500 000 000 ₸ | Цена выше порога |
| `POSITIVE_VALUES` | все значения > 0 | Отрицательные значения |

### API

```javascript
const result = AIEngineerValidator.validate(estimate);
// {
//   valid: false,
//   errors: ['MIN_AREA: Площадь меньше 1 м²'],
//   warnings: ['Высокая цена за м²']
// }
```

# 7. РАБОЧИЕ ПОТОКИ

## 7.1 Заказчик создаёт заказ

```
1. Авторизация (customer)
2. Нажать "Создать заказ"
3. Загрузить фото объекта
4. AI распознаёт тип и параметры
5. Пользователь подтверждает/корректирует
6. AI генерирует смету по разделам
7. Пользователь скачивает PDF или публикует заказ
8. Исполнители видят заказ и откликаются
```

## 7.2 Исполнитель берёт заказ

```
1. Авторизация (executor)
2. Поиск заказов (фильтры: тип, регион, бюджет)
3. Просмотр деталей заказа
4. Подать заявку (указать цену, сроки)
5. Ожидание решения заказчика
6. Заказчик выбирает исполнителя
7. Выполнение работ
8. Загрузка фото отчёта
9. Сдача заказа
10. Получение оплаты (минус 3% комиссии)
```

## 7.3 Админ модерирует

```
1. Авторизация (admin)
2. Панель модерации
3. Просмотр эскалированных заявок
4. Ручная проверка
5. Одобрение / Отклонение
6. Уведомление пользователю
```
