# BuildEstimate Pro – Полное описание программы

## 📋 Общая информация

**BuildEstimate Pro** – это интеллектуальная веб-платформа для автоматизированной оценки строительных работ на основе анализа фотографий объектов. Приложение использует технологии компьютерного зрения и машинного обучения для распознавания строительных конструкций и автоматического расчёта объёмов работ, необходимых материалов и стоимости.

---

## 🎯 Назначение

Программа предназначена для:

1. **Строительных компаний** – быстрая предварительная оценка проектов для составления коммерческих предложений
2. **Прорабов и инженеров** – расчёт материалов на объекте без сложных ручных вычислений
3. **Частных заказчиков** – понимание примерной стоимости ремонта или строительства
4. **Поставщиков материалов** – интеграция для продажи материалов напрямую из сметы

---

## ⚡ Ключевые функции

### 1. AI-распознавание объектов

- Нейросеть анализирует загруженное фото
- Определяет тип конструкции (фундамент, стена, кровля и т.д.)
- Вычисляет размеры на основе референсных точек

### 2. Автоматический расчёт

- Подбор материалов из базы данных
- Учёт норм расхода и запаса (10-15%)
- Расчёт трудозатрат и сроков выполнения

### 3. Формирование сметы

- Детализированный список материалов с ценами
- Разбивка по категориям (основные, расходные, доп. материалы)
- Итоговая стоимость с учётом работ

### 4. Генерация коммерческого предложения (КП)

- Экспорт в PDF одним кликом
- Брендированный шаблон с логотипом компании
- Условия оплаты и сроки выполнения

### 5. Чат-бот ассистент

- Ответы на вопросы по расчётам
- Помощь в работе с интерфейсом
- Информация о материалах и ценах
- Переключение языка интерфейса

### 6. Мультиязычность

- Русский язык (по умолчанию)
- Английский язык
- Возможность добавления других языков

## 🛠 Технологический стек

### Frontend (Текущая версия)

- **HTML5** – семантическая разметка
- **CSS3** – современный дизайн с CSS Variables, Flexbox, Grid
- **Vanilla JavaScript** – без зависимостей, чистый ES6+

### Дизайн

- **Glass-morphism** – эффект матового стекла
- **Тёмная тема** – снижение нагрузки на глаза
- **Градиенты и анимации** – премиальный внешний вид
- **Адаптивная вёрстка** – работает на любых устройствах

### Планируемый Backend (для продакшн-версии)

- **FastAPI (Python)** – REST API для обработки запросов
- **TensorFlow / PyTorch** – ML-модели для распознавания
- **PostgreSQL** – хранение данных пользователей и проектов
- **Redis** – кэширование цен и часто используемых расчётов
- **MinIO / S3** – хранение загруженных изображений

### Пользовательский сценарий

1. Пользователь открывает сайт
2. Загружает фото объекта (перетаскиванием или выбором файла)
3. Видит превью изображения
4. Нажимает "Анализировать"
5. Появляется индикатор загрузки с прогресс-баром
6. Через 2-3 секунды отображаются результаты:
   - Тип обнаруженной конструкции
   - Объём работ в м³
   - Список материалов с количеством и ценами
   - Итоговая стоимость
7. Можно скачать PDF или начать новый анализ
8. В любой момент можно открыть чат-бота для помощи

## 🤖 Чат-бот: команды и ответы

| Команда | Описание | Пример ответа |
|---------|----------|---------------|
| `помощь` / `help` | Список доступных команд | Показывает все команды |
| `оценка` / `estimate` | Инструкция по расчёту | Как загрузить фото и получить оценку |
| `материалы` / `materials` | Информация о материалах | Список поддерживаемых материалов |
| `цены` / `prices` | О системе цен | Как обновляются цены |
| `язык` / `language` | Переключить язык | Меняет RU ↔ EN |
| `контакты` / `contact` | Контактная информация | Email, телефон, Telegram |

## 🚀 Запуск приложения

### Локальный запуск

1. Откройте папку `WebVersion` в проводнике
2. Дважды кликните `run_server.bat`
3. Откройте браузер: `http://localhost:8000`

### Альтернативный способ (PowerShell)

```powershell
cd "C:\Users\User\Desktop\Моя программа\новая прога от гугла\WebVersion"
python -m http.server 8000
# или
npx serve . -l 8000
```
