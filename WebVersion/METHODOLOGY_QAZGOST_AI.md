## 1. ОБЩЕЕ ОПИСАНИЕ

### 1.1 Что это за программа?

**QAZGOST AI** — интеллектуальная веб-платформа для автоматизированной оценки строительных работ.

```
┌─────────────────────────────────────────────────────────────┐
│                      QAZGOST AI                              │
│  "Умный помощник для строительных расчётов и управления"    │
├─────────────────────────────────────────────────────────────┤
│  📸 Фото объекта → 🤖 AI-анализ → 📊 Смета → 📄 PDF        │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 Основные возможности

| Функция | Описание | Статус |
|---------|----------|--------|
| AI-распознавание | Анализ фото, определение объёмов | ⚠️ Заглушка |
| Расчёт смет | Автоматический подбор материалов | ✅ Работает |
| VIP-проекты | Управление строительными проектами | ✅ Работает |
| Engineering | Инженерные решения под ключ | ✅ Работает |
| Чат-система | Коммуникация заказчик-исполнитель | ✅ Работает |
| Финансы | Кошельки, платежи, комиссии | ✅ Работает |

### 1.3 Бизнес-модели
