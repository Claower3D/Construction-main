# Construction Estimator - Android App

🏗️ **AI-приложение для оценки строительных работ**

## Описание

Приложение использует камеру телефона и нейросеть TensorFlow Lite для распознавания строительных объектов на фото и автоматического расчёта стоимости работ.

## Функции

- 📷 Съёмка фото строительного объекта
- 🔍 AI-распознавание объектов (фундамент, стены, окна, двери и др.)
- 💰 Автоматический расчёт стоимости
- 📊 Отображение результатов с уверенностью детекции
- 📄 **Генерация PDF отчётов**
- 📋 **История анализов**
- ⚙️ **Настройки приложения**
- 📤 **Отправка отчётов через мессенджеры и email**

## Требования

- Android 7.0+ (API 24)
- Камера
- ~50 MB свободного места

## Установка и запуск

### 1. Откройте проект в Android Studio

```
File -> Open -> выберите папку AndroidProject
```

### 2. Дождитесь синхронизации Gradle

### 3. Добавьте TFLite модель

Скачайте модель `ssd_mobilenet_v1.tflite` и поместите в:

```
app/src/main/assets/ssd_mobilenet_v1.tflite
```

Ссылка для скачивания:
<https://tfhub.dev/tensorflow/lite-model/ssd_mobilenet_v1/1/default/1>

### 4. Подключите Android-устройство или запустите эмулятор

### 5. Нажмите Run (зелёная стрелка)

## Технологии

- **Kotlin** - язык программирования
- **CameraX** - работа с камерой
- **TensorFlow Lite** - нейросеть для детекции объектов
- **Material Design 3** - современный UI
- **ConstraintLayout** - адаптивный интерфейс
- **PDF Document API** - генерация PDF
- **FileProvider** - безопасная передача файлов
