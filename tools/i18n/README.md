# Переводы интерфейса

Тексты сайта написаны по-русски прямо в компонентах. Перевод — слой поверх страницы
(`frontend/src/i18n/index.js`): русская фраза ищется в словаре выбранного языка и подменяется.

Здесь лежит всё, из чего собираются словари. Скрипты запускаются из этой папки: `cd tools/i18n`.

## Что где

| Файл | Что это |
|---|---|
| `phrases.json` | Русские фразы, собранные из кода сайта и сервера (`harvest*.mjs`), с файлами-источниками |
| `out/*.txt`, `extra.txt` | Английский перевод: `номер|English` и `русская фраза|English` |
| `build.mjs` | Собирает `frontend/src/i18n/dict.en.js` |
| `keys.json` | Реестр фраз для остальных языков: номер фразы = её место в списке и не меняется |
| `lang/<код>/*.txt` | Перевод на язык: строки `номер|перевод`; `patterns.js` — правила с числами |
| `build_lang.mjs` | Собирает `frontend/src/i18n/dict.<код>.js` и проверяет подстановки `{a}`, `{n}` |
| `showf.mjs` | Непереведённые фразы одного файла сайта: `node showf.mjs tr AdminDashboardPage` |
| `ordercheck.mjs` | Фразы с несколькими числами, где порядок чисел стоит проверить глазами |

## Добавить фразы (когда на сайте появился новый текст)

1. Английский: строка `русская фраза|English` в `extra.txt`, затем `node build.mjs` — должно быть «замечаний 0».
2. `node mkkeys.mjs` — новые фразы допишутся в конец `keys.json`.
3. Для каждого языка: `node show.mjs zh 300` покажет непереведённое, перевод — в новый файл `lang/zh/NNN.txt`,
   затем `node build_lang.mjs zh`.

Пока фраза не переведена на язык, сайт показывает её по-английски.

## Числа в переводе

Числа из русской фразы возвращаются в перевод по порядку: первое `{n}` — первое число. Если в языке
порядок слов другой, перевод называет номер числа явно — `{n1}`, `{n2}`…:

    2466|每 {n2} m² {n1} 个        («{n} на {n} м²»: «2 на 10 м²» → «每 10 m² 2 个»)

Номера ставятся либо у всех чисел фразы, либо ни у одного. После перевода: `node ordercheck.mjs <код>`.

## Добавить язык

1. Папка `lang/<код>/`, перевод по очередям (`node show.mjs <код> 300`): 0 — главная и общие надписи,
   1 — оценка стоимости и то, что видит гость, 2 — кабинеты, 3 — служебные разделы сотрудников.
2. `node build_lang.mjs <код>` (язык должен быть в списке `NAMES` в скрипте).
3. В `frontend/src/i18n/index.js`: строка в `LANGS`, в `LOADERS` и в `UNIT_BY_LANG` (шт, дн, чел…); для письма
   справа налево — `dir: 'rtl'`. Подпись списка языков — `GROUP_LABEL` в `components/LangSwitch.jsx`, согласия
   при регистрации — `RegisterPage.jsx`, пометка у юридических документов — `LegalPage.jsx`.
   Файл `AdminDashboardPage.jsx` (кабинет заказчика) числится служебным, но переводится вместе с очередью 1.
4. Проверка: `cd frontend && npm run test:i18n`.

## Состояние

- Английский — полностью.
- Китайский — всё, кроме служебных разделов сотрудников (админка, CRM, аналитика, панель инженера).
- Турецкий — главная, каталоги, вход и регистрация, оценка стоимости, первый экран кабинета; остальное в кабинетах
  пока по-английски.
- Французский, итальянский, испанский (Мексика: «departamento», «celular», «concreto», на «ты») — как турецкий:
  очереди 0 и 1 (главная, каталоги, вход и регистрация, оценка стоимости, первый экран кабинета); остальное
  в кабинетах пока по-английски.
- Английский для Великобритании (`en-GB`) и Канады (`en-CA`) — отдельного словаря нет: основной английский
  перевод проходит через правила написания в `frontend/src/i18n/enVariants.js` (colour, centre, catalogue;
  для Великобритании ещё -ise и flat, для Канады -ize остаётся). Новое слово с разным написанием — строка там же.
