# QazGost — все приложения в одном

Одно Android-приложение (`kz.qazgost.app`) со стартовым экраном выбора:
Заказчик, Исполнитель, Инженер, Менеджер (CRM), Администратор.

- Каждое приложение собирается из своей папки `mobile-*` без изменений и кладётся в `www/<имя>/`.
- Экран выбора — `www/index.html`. Галочка «Сразу открывать последнее» включена по умолчанию.
- Вернуться к выбору: «Назад» на главном экране приложения или ярлык ⇄ у левого края (его можно перетащить).
- Ярлык добавляется в каждое приложение файлом `www/switch.js` при сборке.

Сборка на Windows: `BUILD_ALL_IN_ONE_APK.bat` в корне проекта.
Вручную: `npm install` → `npm run build` → `npx cap sync android` → `android\gradlew assembleDebug`.
Подпись — `.keys/qazgost-debug.keystore`, как у остальных APK.
