# Автоматический анализ состояния бетонных колец (QazGost AI)

Автономная модульная система для автоматического обнаружения железобетонных колец и труб по фотографии с полной локализацией и классификацией дефектов по 8 категориям.

---

## 🎯 Возможности
- **Автоматическая сегментация кольца**: определение геометрии бетонного кольца на лету без хардкода координат.
- **Изоляция центрального отверстия и грунта**: нулевое закрашивание центральной шахты и окружающей земли/фона.
- **Тайловый мультимасштабный CLAHE-анализатор**: обнаружение как тонких волосяных трещин, так и сквозных разломов.
- **Классификация на 8 категорий дефектов**:
  1. `major_crack` — Крупные сквозные трещины и разломы (Красный `#FF0000`)
  2. `thin_crack` — Тонкие и волосные трещины (Красный `#FF1744`)
  3. `branching_crack` — Ответвления и сетка трещин (Красный `#D50000`)
  4. `edge_spall` — Сколы кромки изделия (Жёлтый `#FFD600`)
  5. `spalling` — Выкрашивание и потеря материала (Жёлтый `#FFEA00`)
  6. `surface_erosion` — Эрозия и разрушение поверхности (Оранжевый `#FF9100`)
  7. `cavity` — Раковины, каверны и углубления (Тёмно-оранжевый `#FF6D00`)
  8. `edge_deformation` — Деформация кромки (Оранжево-красный `#FF3D00`)
- **Цветовые слои**:
  - `intact`: Полупрозрачный зелёный `#00C853` (25–35% прозрачности)
  - Дефектные области замещают зелёный цвет и обводятся чётким контуром.

## 🚀 Установка и запуск

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Запуск через CLI
```bash
python detect_ring_defects.py --input path/to/image.jpg --output-dir results --confidence 0.35
```

---

## 📂 Выходные файлы (`results/`)
1. `annotated_result.png` — фото с цветовой разметкой и выносками дефектов.
2. `masks.png` — отдельная карта классов.
3. `defects.json` — детальный JSON со всеми найденными дефектами (полигоны, координаты, площади, длины, severity).
4. `summary.json` — сводный отчёт (общее состояние, количество трещин, сколов, каверн, % повреждений).
