# Датасет строительных объектов для QAZGOST AI

## 📋 Описание

Датасет для обучения модели распознавания строительных объектов на фотографиях.
Разработан специально для строительной индустрии Казахстана.

## 📄 Формат аннотаций (YOLO)

Каждый `.txt` файл содержит аннотации в формате:

```
<class_id> <x_center> <y_center> <width> <height>
```

Все координаты нормализованы (0.0 - 1.0).

**Пример:** `img_0001.txt`

```
0 0.512 0.384 0.256 0.128
7 0.234 0.567 0.089 0.234
19 0.789 0.123 0.045 0.156
```

## 📸 Требования к изображениям

### Технические требования

- Формат: JPEG, PNG
- Минимальное разрешение: 640×640 px
- Рекомендуемое разрешение: 1280×720 px или выше
- Соотношение сторон: любое (YOLO поддерживает)

### Требования к содержимому

- Фотографии реальных строительных объектов
- Разные условия освещения (день, вечер, пасмурная погода)
- Разные ракурсы (сверху, сбоку, под углом)
- Разные этапы строительства
- Включить фото с людьми для калибровки масштаба

### Рекомендуемое количество

| Класс | Минимум | Рекомендуется |
|-------|---------|---------------|
| Приоритет 🔴 | 500 | 1000+ |
| Приоритет 🟡 | 200 | 500+ |
| Приоритет 🟢 | 100 | 300+ |

**Итого:** минимум 3,000 изображений для базовой модели.

## 🏷️ Инструменты для разметки

### Рекомендуемые

1. **CVAT** (Computer Vision Annotation Tool)
   - Веб-интерфейс
   - Поддержка YOLO формата
   - Бесплатный

2. **Label Studio**
   - Локально или в облаке
   - Много форматов экспорта
   - Open Source

3. **Roboflow**
   - Облачный сервис
   - Автоаннотация
   - Аугментация данных

### Экспорт

После разметки экспортировать в формате **YOLO v5/v8 PyTorch**.

## 📊 Метрики качества

При обучении отслеживать:

- **mAP@0.5** - основная метрика
- **mAP@0.5:0.95** - строгая метрика
- **Precision** - точность
- **Recall** - полнота
- **F1-score** - гармоническое среднее

**Целевые показатели:**

- mAP@0.5 > 0.75
- mAP@0.5:0.95 > 0.50
- Recall > 0.70

## 🚀 Обучение модели

```bash
# Установка YOLOv8
pip install ultralytics

# Обучение
yolo detect train data=data.yaml model=yolov8n.pt epochs=100 imgsz=640

# Валидация
yolo detect val data=data.yaml model=runs/detect/train/weights/best.pt

# Экспорт в ONNX
yolo export model=best.pt format=onnx
```
